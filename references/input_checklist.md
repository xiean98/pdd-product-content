# 输入信息清单（一个拼多多商品需要备齐什么）

## 一、用户每次的标准输入

| 类别 | 项目 | 必需 | 说明 |
|---|---|---|---|
| 品名 | 商品品名/标题方向 | 是 | 没有成品名就给关键词方向，由 `title.md` 拟 |
| 图片 | 实物图 | 是 | 见下方角度要求；套装每件都要 |
| 规格 | 尺寸表 | 建议 | 直径/长宽/高即可，不写容量 |
| 规格 | 件数/套装清单 | 套装必需 | 每件名称、数量 |
| 资质 | 材质/工艺/适用性 | 建议 | 仅采用用户已确认的事实 |

### 实物图标准 4 张/件（用户固定拍法）
1. **45° 角商品正图**：细节最多，用于主视觉/封面/轮播首图。
2. **侧视图**：显器型轮廓、高度、口沿与外壁花纹。
3. **俯视图**：显盘心/碗内、花纹布局、中心是否留空。
4. **底视图**：显圈足/底座形状与颜色、注浆口。
- 套装每件各给这 4 张；异形件俯视图需看清最长边与宽沿。
- 少于 4 张时一致性风险更高，抽查更严并在交付说明标注。

## 二、生成各物料所需的信息映射

- **标题**：品类大词、风格词、材质、规格/件数、使用/送礼场景。
- **轮播图 / 封面**：视觉基因（配色/花纹/材质/器型）、件数、品牌（可选）。
- **尺寸标注图**：每件实测直径/长宽/高；参照物（勺、蛋、硬币、手）。
- **详情页**：上述全部 + 卖点 + 使用场景 + 工艺/温馨提示。

## 三、默认口径与合规红线

默认口径（陶瓷餐具，用户已授权）：**不写容量**；**可写“可微波炉加热”**；洗碗机/烤箱/消毒柜未确认不写；**礼盒、售后暂不做、不上屏**。

以下在用户明确确认前，**不得写进标题、图片文字或卖点**：
釉上彩/釉下彩（未确认时）、骨瓷/烧制温度/“高温”、产地、品牌名与 Logo、“食品级/食品接触用”认证、“第一/国家级/最”等违禁词。

- 需要呈现但未确认：用中性词（如“釉面光滑，好洗好收拾”）或留占位 `___（待确认）`。
- 服务栏、容量默认省略，不硬编。

## 四、缺失信息的提问原则

- 仅当缺失项会**实质改变产物或造成违规**时才问，且一次性问完（品名方向、尺寸、件数、关键资质）。
- 不影响成品的次要项，用合理默认并在交付说明里标注，不反复追问。
