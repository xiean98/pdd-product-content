# 输入信息清单（一个电商商品需要备齐什么）

## 一、用户标准输入

| 类别 | 项目 | 必需 | 说明 |
|---|---|---|---|
| 品名 | 商品品名/标题方向 | 是 | 没有成品名就给关键词方向，由 `title.md` 拟 |
| 图片 | 实物图 | 是 | 见下方角度；套装每件都给 |
| 规格 | 尺寸表 | 建议 | 直径/长宽/高，不写容量 |
| 规格 | 件数/套装清单 | 套装必需 | 每件名称、数量 |
| 资质 | 材质/工艺/适用性 | 建议 | 仅采用用户已确认的事实 |

### 实物图（用户固定拍法，按这个角度口径）

- **图0 = 商品标签**：看品名/花色/材质/执行标准/资质用，**不入图**。
- **图1 = 45° 角正图**：细节最多，用于主视觉/主图/手持。
- **图2 = 俯视（正俯）**：看盘心/碗内花纹、中心实心/线圈/留白。
- **图3 = 底视（倒扣）**：看圈足形状与颜色、**底足品牌底标/底款**。
- **图4 = 侧视（水平正侧）**：看器型深浅轮廓、外壁花纹、口沿。
- 套装每件各给一套；异形件俯视要能看清最长边。
- 外壁花纹、是否高脚、圈足颜色、底标这些"非主视角"信息必须看图2/图3/图4，只看 45° 图最容易漏。
- 少于这套时一致性风险更高，该件高风险锚点按"必查"处理，并在交付说明标【缺图】。
- 器型/比例以实物为准，品名仅作检索词；实物与名字矛盾（"长方盘"看着偏方）不要据名字改图。

## 二、生成各物料需要的信息

- **标题**：品类大词、风格词、材质、规格/件数、场景。
- **主图/轮播**：视觉基因（本体配色/花纹/器型）、件数；背景/场景自由。
- **尺寸图**：实测直径/长宽/高；参照物或手持可选。
- **详情页**：上述 + 卖点 + 使用场景 + 工艺/温馨提示。

## 三、默认口径与合规红线

默认口径（陶瓷餐具，用户已授权）：**不写容量**；可写"可微波炉加热"；洗碗机/烤箱/消毒柜未确认不写；礼盒、售后暂不上屏。

以下在用户明确确认前，**不得写进标题、卖点或宣传文字**：
釉上彩/釉下彩、骨瓷/烧制温度/"高温"、产地、品牌宣传语、"食品级/食品接触用"认证、"中华老字号"等称号、"第一/国家级/最"等极限词。

**区分两类品牌信息**：
- **器物本体上的底标/底款/Logo**（图3 底足上印的、图0 标签能佐证的）：属于商品外观，**按实物照还原**，不主动去掉。
- **拿品牌/资质做宣传背书**（标题、卖点、角标、详情里强调"中华老字号/食品级/认证"）：必须用户确认后才上。

需要呈现但未确认：用中性词（如"釉面光滑、好洗好收拾"）或留占位 `___（待确认）`；容量、服务栏不硬编。

## 四、缺失信息的提问原则

- 仅当缺失会**实质改变产物或造成违规**时才一次性问完（品名方向、尺寸、件数、关键资质）。
- 以下必须问、不脑补：① 某件完全缺图或缺关键角度，无法判断外壁花纹/是否高脚/器型/底标；② 实物外观与品名/尺寸表/常识明显矛盾，多看几个角度仍不能确定；③ 同款存疑、尺寸数字对不上。
- 不影响成品的次要项，用合理默认并在交付说明标注，不反复追问。
