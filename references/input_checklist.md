# 输入清单 与 合规口径（本文件是合规红线的唯一事实源）

标题、封面/轮播/详情页图中文字、SKU 名的所有合规问题都以本文件为准，其他文件不再重复。

## 一、标准输入

| 类别 | 项目 | 必需 | 说明 |
|---|---|---|---|
| 品名 | 品名/标题方向 | 是 | 无成品名给关键词方向，按 `title.md` 拟 |
| 图片 | 实物图 | 是 | 4 张/件，见下；套装每件都要 |
| 规格 | 尺寸表 | 建议 | 直径/长宽/高，不写容量 |
| 规格 | 件数/套装清单 | 套装必需 | 每件名称、数量 |
| 资质 | 材质/工艺/适用性 | 建议 | 只采用用户已确认事实 |

### 实物图标准 4 张/件
1. **45° 角正图**：细节最多，用于主视觉/封面/轮播首图。
2. **侧视**：器型轮廓、高度、口沿与**外壁花纹**（大汤碗/非高脚碗外壁有无花，只看俯拍最易漏）。
3. **俯视**：盘心/碗内花纹、中心实心/线圈/留白。
4. **底视（倒扣）**：圈足接地端面颜色、足心纹、注浆口（高脚碗常见侧视脚绿、底视接地圈白，须按视角分开）。
- 异形件俯视图需看清最长边与宽沿；少于 4 张时该件高风险锚点一律按“必查”，并在交付说明标注【缺图】。

各物料信息映射：标题→品类大词/风格词/材质/件数/场景；轮播封面→视觉基因/件数；尺寸图→实测尺寸+参照物；详情页→上述全部+卖点+场景+固定文案。

## 二、默认口径（陶瓷餐具，用户已授权）

- **不写容量**；可写 **“可微波炉加热”**；洗碗机/烤箱/消毒柜未确认不写。
- 礼盒、售后暂不做、不上屏。

## 三、未确认前禁止写进标题/图中文字/卖点

釉上彩/釉下彩、骨瓷/烧制温度/“高温”、产地、品牌名与 Logo、“食品级/食品接触用/医用级”认证、容量、耐温、发货时效、“第一/国家级/最/顶级”等极限词与未授权称号。

- 换品类（玻璃/塑料/金属/竹木）时功能适用性重新确认。
- 需要呈现但未确认：用中性词（如“釉面光滑，好洗好收拾”），或留占位 `___（待确认）`，不硬编。
- 固定文案“工艺说明”里“釉下彩”仅在该品确为釉下彩时保留，否则改中性（见 `craft_notice.md`）。

## 四、缺失信息提问原则

- 仅当缺失项会**实质改变产物或造成违规**时才问，且一次性问完（品名方向、尺寸、件数、关键资质）。
- 外观矛盾/缺图/同款存疑/拿不准的处理归 `feature_profile.md` 红线：**先问用户、答复前不出图**，不脑补。
- 不影响成品的次要项用合理默认并在交付说明标注，不反复追问。
