# 拼多多商品标题（品名）生成

## 标题公式（约 30 汉字内，关键词按权重前置）

`[风格/花纹词] + [工艺/材质] + [品类大词] + [规格/件数] + [器型长尾] + [场景/人群]`

- 品类大词（放前面卡搜索）：碗碟套装、餐具套装、碗盘、碗筷套装、陶瓷碗……
- 风格词：复古、日式、手绘、田园、小清新、ins、侘寂、奶油风、新中式……
- 材质：陶瓷、粗陶（釉下彩/骨瓷**需确认**才能写）。
- 规格：10件/整套、一人食、X寸；器型：饭碗/汤碗/深盘/浅盘/鱼盘。
- 场景：家用、乔迁新居、新婚、送礼、宿舍、小家庭。

## 输出要求

- 给 **1 条主推 + 2-3 条不同侧重备选**（送礼向/风格向/简约向）。
- 通顺可读、不堆无关热词、同一词不重复；只写已确认事实。
- 合规红线（极限词、未确认工艺/功能、品牌、他人 IP 等）统一见 `input_checklist.md`，不在标题与图中文字中出现。

## 示例（陶瓷餐具套装）

- 主推：焦糖花手绘陶瓷碗碟套装家用复古餐具整套10件碗盘鱼盘乔迁送礼
- 备选：日式焦糖花陶瓷餐具套装手绘复古碗碟家用饭碗汤盘鱼盘整套十件
- 备选：复古焦糖花碗碟套装家用陶瓷餐具乔迁新居礼物新婚送礼碗盘10件
