# 一致性抽查（只核商品本体，风格不查）

目标：把核对精力只放在"商品长什么样"上；背景、场景、版式、风格一律不查，避免为不影响一致性的东西消耗时间。

## 第 0 步：档案校验（先确认基准对）

- 抽查锚点来自特征档案；档案错了，再严的抽查也会"按错答案对出全对"。
- 建档规范见 `feature_profile.md`：每条高风险锚点要能指到具体实物图角度，【缺失/推断】标清楚，矛盾先问用户。
- **用户一旦打回 = 档案级错误信号**：不只改被指出的那张，回到实物逐件复核同类全部单品、回查所有已出图，修订档案后再重出。

## 查什么 / 不查什么

| 必查（商品本体） | 不查（放开，自由发挥） |
|---|---|
| 器型/比例（以实物为准、不按名字）、碗口是否正圆、是否高脚/圈足 | 背景、场景、道具、光影、色调 |
| 口沿/边饰、外壁花纹有无、花纹增减/错花种、花心、中心实心/线圈/留白 | 构图、角度、裁切、版式、字体、有无文字 |
| 圈足端面颜色、底足品牌底标/底款（按实物） | 尺寸图选 A 白底还是 B 场景化、详情页排版风格 |
| **尺寸数字、名称、件数/套装点数** | 氛围感、"好不好看"这类主观项（交给用户挑） |

## 流程

1. **首件试点全检**：新商品第一张（或主图/首屏/尺寸图），对上面"必查"项逐项核对（可多区域裁剪）。过了→后续按抽查；不过→改提示词重出，仍算试点。
2. **其余每张 1 个主锚点**：只裁"最显眼商品的最易错点"（通常是主商品口沿/盘心/外壁花纹），一次并置核对，不做整图全盘。
3. **必查不抽样**：尺寸数字与名称每张必查；多件同框/全家福/整桌**逐只查碗口并逐件点数**，不放宽。
4. **错误升级**：任一必查项出错 → 该批立即升级全检，并在所有已出图里回查同类元素，定位提示词共性后重出受影响图。
5. 全部通过再归档交付；说明已确认范围与【推断/缺失】件。

## 工具

- 用 `scripts/spot_check.py` 自动裁剪生成图锚点并与实物并置（`--gen --real --box --out`，相对坐标）。
- 尺寸/名称/固定文案用脚本叠字，从源头消除数字错误（见 `size_chart.md`、`detail_pages.md`）。
