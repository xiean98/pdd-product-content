# 尺寸标注图生成

为每件单品出一张（或在详情页尺寸屏分组呈现）。数字必须来自用户尺寸表或实物，**不得估算冒充实测**。

## 标准样式

- 纯白或极浅米灰背景；顶部产品名标题（深色、简洁）。
- 多视图：俯视图（或正视）+ 侧视图 + 底视图，排列整齐。
- **细灰色标注线**：水平箭头标直径/长边/短边，垂直箭头标高度；数字与产品同色系，不用大红大蓝。
- 可放参照物（木勺、鸡蛋、硬币、手）帮助感知大小。
- 单位 cm；异形标长×宽×高。

## 底图生成（无字三视图）+ 脚本叠数字（推荐）

1. 先用图像模型生成**纯白背景、无任何文字与标注线**的三视图底图（俯视 + 侧视 + 底视横排）。
2. 再用脚本在底图上叠加尺寸线与数字：`scripts/make_size_chart.py`（坐标相对值）；批量可按项目里的 `auto_chart.py` 自动检测三视图 bbox。**数字不交给模型写**，避免错字/串位/模型顺带改器型。
3. 底图外观严格复制实物：边饰/花纹/配色一致、**外壁花纹、是否高脚、圈足端面颜色（按底视）、中心实心/线圈/留白**都要对；面状图案（实心绿圆）写"实心 X 色、内部 X 纹"。
4. **器型比例以实物为准，严禁为凑名字/尺寸去拉伸或变形底图**（"长方盘"偏方就画偏方）。
5. 容量等未确认项不标；需要时留 `___（待确认）`。

## 改图与局部改色的注意

- 器物颜色/花纹要改（如高脚台脚色），**尽量在"无字底图"阶段用图像编辑整图重出**，并在提示词里强约束"只改该部位、其余与数字/文字/标注线保持"。
- 不要用图像处理在已叠加数字的成图上手工 mask 给立体器物上色（脚/足等曲面极易溢出边缘）；文字类小改动（如标签改字）可用取背景色羽化填充 + 同字体重排，但完成后逐字核对。

## 套装尺寸屏（详情页内）

- 纵向分组：碗组、圆盘组、异形（鱼盘/方盘），每组代表件 + 标注。
- 若单品很多，只展示代表尺寸并在全家福屏给完整清单，避免一屏数字过密。

## 校验

- 逐张核对：名称、每个数字（直径/高/长宽）与尺寸表一致；多视图是否同一商品。
- 数字是高风险项，尺寸图/尺寸屏按 `qa_sampling.md` 必查数字。
