# 尺寸标注图生成

每件单品出一张（或在详情页尺寸屏分组）。数字必须来自用户尺寸表或实物，**不得估算冒充实测**。

## 标准样式

- 纯白或极浅米灰背景；顶部产品名标题（深色、简洁）。
- 多视图：俯视（或正视）+ 侧视 + 底视横排整齐。
- **细灰色标注线**：水平箭头标直径/长边/短边，垂直箭头标高度；数字与产品同色系，不用大红大蓝。
- 可放参照物（木勺、鸡蛋、硬币、手）；单位 cm，异形标长×宽×高。

## 底图（无字三视图）+ 脚本叠数字（推荐）

1. 先用图像模型生成**纯白背景、无任何文字与标注线**的三视图底图（俯视+侧视+底视横排）。
2. 再用脚本叠尺寸线与数字：`scripts/make_size_chart.py`（相对坐标，用法见文件头）；批量可用项目里的 `auto_chart.py` 检测三视图 bbox。**数字不交给模型写**，避免错字/串位/顺带改器型。
3. 底图外观严格复制实物：边饰/花纹/配色、**外壁花纹、是否高脚、圈足端面颜色（按底视）、中心实心/线圈/留白**都对；面状实心圆写“实心 X 色、内部 X 纹”。
4. **器型比例以实物为准，严禁为凑名字/尺寸拉伸变形**（“长方盘”偏方就画偏方）。
5. 容量等未确认项不标，需要时留 `___（待确认）`（合规见 `input_checklist.md`）。

## 改图与局部改色

- 器物颜色/花纹要改（如高脚台脚色），尽量在**无字底图阶段**用图像编辑整图重出，强约束“只改该部位、其余保持”。
- 不要在已叠数字的成图上手工 mask 给立体曲面上色（脚/足等曲面易溢出）；纯文字小改可取背景色羽化填充+同字体重排，完成后逐字核对。

## 套装尺寸屏（详情页内）

纵向分组（碗组、圆盘组、异形组），每组代表件+标注；单品很多时只展示代表尺寸，完整清单放全家福屏，避免一屏数字过密。

## 核对

数字与名称每张必查（直径/高/长宽对尺寸表）、三视图是否同一商品，规则见 `qa_sampling.md`。
