# 尺寸图（两种形式，任选或都做）

数字必须来自用户尺寸表或实物实测，**禁止估算冒充实测**；实物与尺寸表矛盾时先问用户。

## 形式 A：标准三视图白底图（参数严谨）

- 纯白或极浅底，**俯视 + 侧视 + 底视**横排；顶部产品名。
- 角度严格按用户实物拍法（见 `input_checklist.md` / `feature_profile.md`）：
  - **俯视 = 正俯视（图2）**；**侧视 = 水平正侧视图（图4）**；**底视 = 倒扣（图3）**。
  - **不要用 45° 斜俯视图冒充侧视图**（会看不到该有的侧轮廓，且碗心花纹容易丢）。
- 底足上的**品牌底标/底款按实物还原**（实物有就画，不要自作主张去掉）；花纹、外壁、圈足颜色全部按对应角度实物。
- **投影去净**：白底三视图不要保留器物下方的投影（用户要干净白底）。
- 标注线规范（`scripts/make_size_chart.py` 相对坐标叠线；批量可写脚本自动检测）：
  - 水平箭头标直径/长边，垂直箭头标高度，异形加短边；单位 cm。
  - **标注线必须在器物轮廓之外，不压图**；高度线取整个侧视图器物最外缘（含碗腹）+留白，右侧放不下就放左侧。
  - 直径/长边线两端对准**碗口实际边缘**，不要把阴影、相邻视图、空白算进去；检测时排除深色投影。
  - 细灰线、同色系数字，不用大红大蓝。
- **数字/名称一律脚本 PIL 叠加，不交给模型写**。

## 形式 B：场景化 / 营销式尺寸图（允许且鼓励）

不强制白底三视图，可做得更有网感：

- 手拿着比大小、参照物（手、手机、硬币、筷子、勺、蛋）、餐桌/厨房/宿舍场景。
- 带卖点文字标签，例如"X寸大小刚刚好 / 长X宽X / 宿舍|家用|送礼"。
- 真人入镜、生活化、卡通活泼、海报式均可，风格与主图统一或有意反差都行。
- 尺寸数字仍必须准确、清晰，建议出无字底图后脚本叠字保证不错。

## 通用

- 异形标长×宽×高；不写容量；未确认的耐温/资质不标，需要留 `___（待确认）`。
- 同一批尺寸图样式统一；但**不同批次、不同商品可以换形式（A/B）和风格，不必千篇一律**。
- 校验：数字与名称每张必查（高风险，见 `qa_sampling.md`）；外观按实物，三视图要同一件商品。
