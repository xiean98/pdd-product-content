# 主图 / 轮播图（封面已并入，一套出 12 张）

拼多多商品顶部的一组方图。**封面不再单独做**：封面就是这套图里的首图。

## 数量

- 默认一套 **12 张方图（1536×1536）**；平台最多放 10 张，多给 2 张**供用户挑选**。
- 其中 **1–2 张是带标题/卖点的封面式主图**（排最前），其余无文字或只带轻量标签。
- 用户没特别要求时，按这个数量走；不要为了凑数重复同质画面。

## 风格自由，刻意做差异（最重要，解决"呆板、一个模板"）

- **除"商品本体"外，其余全部放开**：背景、场景、道具、光影、角度、构图、色调、字体、版式、要不要文字，都自由发挥，不套固定模板。
- 鼓励混搭、真人手持、生活化、有网感的拍法。方向池（任选、混搭、可自创，不限）：
  - 手持实拍 / 手拿比大小 / 入镜一双手
  - 餐桌、厨房、窗边、户外、办公室、宿舍等真实使用场景
  - 纯色棚拍 / 撞色背景 / 莫兰迪 / 高饱和 / 深色质感 / 高明度
  - 正俯 flatlay / 45° / 平视 / 微距特写 / 局部裁切
  - 装食物、配餐具、倒水、热气腾腾、节日氛围
  - 带文字卖点标签（如"X寸刚刚好""长X宽X""宿舍|家用|送礼"）、海报式、标签贴纸式
  - 童趣卡通、ins、侘寂、轻奢……商品气质合适就用
- 一套 12 张要**明显有差异**：明暗、远近、横竖构图、场景、有无人物交替，不要 12 张一个味。
- `assets/style_memory/` 只在**没灵感或用户点名某种风格**时翻阅，默认不强制匹配、不强制记录"已用组合"。
- 只有一条配色边界：**商品本体的配色不得改**；环境色可自由，且不要让背景色盖过商品。

## 必须覆盖的信息（很松，满足即可，单张形式不限）

- 主图（带标题，1–2 张）
- 商品全貌 + 关键角度：至少让人看清主视角、盘心/碗内（俯视）、关键侧面或底视
- 细节特写：花纹 / 质感 / 口沿 / 工艺
- 大小或使用感：手持、参照物、装食物、成组摆放

不必凑固定清单，也不必每张一个主题；同一角度可以多拍几种不同氛围供挑。

## 商品本体一致性（唯一红线）

只锁"商品长什么样"，规则全部见 `feature_profile.md`：器型/比例、边饰、花纹（含外壁、中心实心/线圈/留白）、圈足/底标、配色位置，每张必须与实物一致。

- 多件同框/全家福：碗口正圆、逐件点数、件数与器型对、禁止碗盘相互嵌套变形；这类图逐只查。
- 提示词里**商品本体描述只写一次**（取自特征档案），12 张复用同一套本体描述，只改场景/角度/构图，不每张重写。
- 文字：主图短标题可由模型出，但必须逐字核对；多行卖点/价格/长文案优先出无字底图再用脚本叠字（数字、文字零差错）。
- 负面清单只写"会改错商品本体"的项（如错误宽边色、中心该空却画满、大汤碗画成素碗、冷白瓷、塑料感），不限制背景风格。

## 出图与抽查

- 可先出 2–3 张**不同风格**的小试点，方向对了再批量；或直接出 12 张供挑。
- 抽查见 `qa_sampling.md`：只核商品本体（器型/花纹/盘心/碗口/件数），**背景、场景、道具、光影、版式一律不查**。
