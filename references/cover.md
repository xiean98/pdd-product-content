# 封面主图生成（风格自适应 + 实物一致）

版式与风格来自内置记忆库 `assets/style_memory/`，但每次视觉结果必须随实物变化。

## 一、先做风格匹配（避免雷同）

1. 从特征档案取视觉基因（主色冷暖、花纹气质、材质光哑、器型线条、明度），按 `assets/style_memory/style_families.md` 选 **1 个主风格族（必要时 +1 融合族）**，只读命中的 `families/<族>.md` 取六要素。
2. **把实物主色设为画面主色/点缀色**（从实物取色，不套固定配色）；背景选与主体拉开明度的中性色。
3. **族内变化轮换**：角度（45°斜俯/正视/正俯 flatlay/平视特写）、道具（每类挑 1-2 件、组合不固定）、构图重心轮换；已用的“风格族+角度+主道具”登记到 `products/<产品名>/风格使用记录.md`，同系列不重复。

## 二、提示词模板

```
生成一张[方图/竖图][电商封面]。[风格族名]风格，[光影/明度/背景]描述。
下列商品（外观严格复制对应实物图）成组摆放：
@图片N（名称，边饰编号…，花纹编号…，布局…）…
全部[胎釉/肌理/工艺]，配色限定为<配色清单>。
道具：<按风格族与实物配色挑选>。
强约束：器型/边饰/花纹/配色/位置与实物一致，不得改、增减、混边饰；
负面：<品类相关负面，如冷白瓷、绿宽边、中心画满、塑料感、廉价促销>。
文字：标题“…”副标题“…”（字体按风格族；无促销角标/价格/按钮）。
```

## 三、一致性硬约束（写进每条提示词）

- 每件商品绑定对应实物参考图，逐一写明器型、边饰（外缘/内缘）、花种与花蕊、布局，明确“何处该空”，圈足颜色按实物。
- 餐具负面清单：冷白光滑瓷、错误宽边色、把散花画成中心花束、实心圆画成空心线圈、大汤碗画成素碗、塑料感。
- 文字只放标题/副标题/眉题，不放价格、按钮、促销角标；合规口径见 `input_checklist.md`。

## 四、多件同框 / 全家福防碗口畸变（实测高发）

斜侧 + 多碗同框 + 碗盘嵌套叠放时，模型极易把碗口画成歪口/贝壳形/缺口，或在碗里叠出不存在的畸形物件。全家福、整组英雄图是重灾区：

- **明令禁止碗盘相互嵌套、叠放、装入**；每件独立平放台面。
- 写死“**所有碗口必须规整正圆，透视下呈对称椭圆，绝不允许歪口/缺口/波浪/不规则**”。
- 大合影优先**正俯拍 flatlay 或正面平视**，少用强斜侧；同框高脚碗越多越易畸变，适当减少。
- 非高脚大汤碗显式写“外壁有 X 花纹、无高脚台”；面状实心圆写“实心 X 色、内部 X 纹”。
- 全家福还要**逐件点数**（件数/器型计数，见 `qa_sampling.md`）；首版没过就减件、改视角重出，不硬修。

## 五、数量与节奏

封面 3-5 张：1 张整组英雄、1 张特写、1 张俯拍、可选美食/氛围。先出 1 张试点全检通过后再批量（核对规则见 `qa_sampling.md`）。
