# 封面主图生成（风格自适应 + 实物一致）

用户不再提供参考图：版式与风格来自内置记忆库 `assets/style_memory/`，但每次视觉结果必须随实物变化。

## 一、先做风格匹配（核心，避免雷同）

1. 从特征档案取视觉基因：**主色、花纹气质、材质质感、器型线条、明度**。
2. 按 `assets/style_memory/style_families.md` 的匹配规则选出最契合的 **1 个主风格族（必要时 +1 个融合族）**，再读 `assets/style_memory/families/<族>.md` 取该族六要素（配色/光影/道具/字体/构图）。
   - 例：暖白釉 + 手绘野花 → 手绘田园 / 日式治愈；冷白 + 极简线条 → 北欧极简；粗陶 + 大地色 → 日式侘寂；描金 + 深色 → 现代轻奢。
3. **把实物主色设为画面主色/点缀色**（从实物取色，不套用固定配色），背景选与主体拉开明度的中性色。
4. 在风格族内做**变化轮换**，避免每次同构图：
   - 角度：45°斜俯 / 正视 / 正俯 flatlay / 平视特写 中轮换。
   - 道具库中每类挑 1-2 件，组合不固定；构图重心位置轮换。
   - 记录当次已用的“风格族+角度+主道具”，同系列多张之间不重复。

## 二、提示词模板

```
生成一张[方图/竖图][电商封面]。[风格族名]风格，[光影/明度/背景]描述。
下列商品（外观严格复制对应实物图）成组摆放：
@图片N（名称，边饰编号…，花纹编号…，布局…）…
全部[胎釉/肌理/工艺]，配色限定为<配色清单>。
道具：<按风格族与实物配色挑选>。
强约束：器型/边饰/花纹/配色/位置与实物一致，不得改、增减、混边饰；
负面：<品类相关负面，如冷白瓷、绿宽边、中心画满、塑料感、廉价促销>。
文字：标题“…”副标题“…”（字体按风格族；无促销角标/价格/按钮）。
```

## 三、一致性硬约束（写进每条提示词）

- 每件商品绑定对应实物参考图；逐一写明器型、边饰（含外缘/内缘）、花种与花蕊、布局。
- 明确“何处该空”；圈足颜色按实物。
- 负面清单按品类追加：餐具禁冷白光滑瓷、错误宽边色、把散花画成中心花束。
- 文字只放标题/副标题/眉题，不放价格、按钮、促销角标。

## 四、数量与节奏

- 封面建议 3-5 张：1 张整组英雄图、1 张特写、1 张俯拍、可选美食/氛围图。
- 先出 1 张试点，按 `qa_sampling.md` 全检通过后再批量。
