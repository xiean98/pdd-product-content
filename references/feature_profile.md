# 实物特征档案（视觉基因提取）

出图前必须先建此档案。目标：把“看起来差不多”的实物，拆成模型无法自由发挥的、可逐条核对的结构化事实。档案是提示词与抽查的唯一基准。

## 提取步骤

1. 通览全部实物图，先归纳**系列/单品共性**：胎釉底色与光泽（如奶白暖釉、冷白亮釉、哑光陶土）、表面肌理（光面/手作凹凸/颗粒）、工艺观感（手绘/印花/浮雕）。
2. 拆**轮廓与器型**：收口/敞口、深浅、圈足样式、异形（椭圆/方/花边）。
3. 拆**边饰/轮廓装饰**并编号（A/B/C…）：这是最易被模型画错、也最能区分真伪的部位，记录颜色、宽度、图案（格纹/波点/实线/虚线/分段竖线）、位置（外缘/内缘）。
4. 建**花纹元素库**并编号（F1/F2…）：花种、瓣数与形态、**花蕊颜色与形态**（密点/白点/纯色）、枝叶、配色；记录花纹在器面上的**布局**（中心花束/宽沿散花/四角散花/中心留空）。
5. 记录**配色清单**（限定色名），画面配色不得超出此清单。
6. 套装：列**单品规格表**（名称 + 直径/长宽/高 + 对应边饰/花纹编号）；标注哪件缺实物图（需推断时写明依据）。

## 档案模板

```markdown
# <系列名> 特征档案
## 共性
胎釉： ；肌理： ；工艺观感：
## 器型
## 边饰库
- A …（颜色/宽度/图案/位置）；适用：…
- B …
## 花纹元素库
- F1 名称：瓣数/花蕊/配色
## 配色清单
## 布局规则（中心/沿/角，何处该空）
## 单品规格表
| 名称 | 直径 | 高 | 边饰 | 花纹 | 实物图 |
## 一致性核对清单（高风险锚点，逐条可判）
1. …口沿是否为…  2. …中心是否留空  3. …
```

## 关键经验（避免重蹈）

- 边饰务必区分到“外缘 vs 内缘”“实线 vs 虚线”“格纹配色”，笼统写“花边”必被自由发挥。
- 明确写出“**哪里不该有花**”（如宽沿散花的盘心必须空），否则模型会默认填满。
- 圈足/底座颜色单列，避免模型套用其他参考图的撞色底座。
- 缺图单品：用“同花纹 + 已知器型”推断，并在交付时显式说明，不冒充实拍。
- 档案落盘保存到当次项目目录；同一商品后续改图直接复用，不重建。
