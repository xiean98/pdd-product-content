# 实物特征档案（视觉基因提取）

出图前必须先建此档案。档案是提示词与抽查的唯一基准——**基准错了，后面抽查再严也会"按错误答案对出全对"**，所以建档质量高于一切。

## 红线（先读，违反必返工）

1. **以实物图为唯一准绳**：品名、尺寸表、常识都不能用来推断外观。名字叫"长方盘"，实物可能偏方正。
2. **禁止用图像工具（拉伸/变形/局部重绘）改变器物形状**去凑名字或尺寸。实物只能被如实记录，不能被"修"成你以为的样子。
3. **不确定就先停下问用户，严禁带着疑问自行判断或生成图片（用户明确要求）**：只要遇到缺图/缺角度、实物与名字/尺寸/常识矛盾、"是不是同款"不确定、或某个高风险锚点（外壁花纹/是否高脚/器型比例/实心还是线圈）看了多角度仍拿不准，**先把问题列出来一次性问用户，得到答复前不要为相关件生成任何图片**。宁可多问一句，也不要先按猜测出图再返工。
4. 每条外观结论都要能指到"哪件、哪张图、哪个角度"；看不到的部位标【缺失】，不得用别的件补全后冒充实拍。
5. 同系列**同名不同尺寸的款，是否同器型只能由用户确认或实物图证实**，不能看着像就当成同款（见证据等级【同款锚定】）。

## 逐件建档（一件一卡，逐角度看全）

- 套装必须**逐件**建，不能只看合集图或俯拍。每件至少看四个角度：
  - **俯视**：碗内 / 盘心花纹、中心是实心色块 / 空心线圈 / 留白；
  - **侧视**：**外壁有无花纹**、口沿、器型深浅、**是否高脚 / 有无高脚台**、台身颜色；
  - **底视（倒扣）**：圈足接地端面颜色、足心纹；
  - **特写**：花纹/边饰细节。
- **外壁花纹、有无高脚、圈足**这些"非主视角"信息，只看俯拍最容易漏（团圆碗被画成素碗、高脚碗足色误判，均因此）。
- **同一部位在不同视角可能不同**：高脚碗侧视台身是绿色、倒扣底视的接地圈却是奶白、足心一朵小绿三叶。必须按视角分别记录，不许看一个视角就给整只件下结论。
- 外观相似的**相邻单品并置对比着建**（如 9 寸 / 10 寸饭盘花纹易对调），防止张冠李戴。

## 证据等级（每条结论必须标注）

- 【实物确认·角度】：在该角度实物图里直接看到。
- 【同款锚定·来源款】：同系列**同名不同尺寸**的款（如 4.65 寸 / 5.1 寸高脚碗），**经用户确认或实物证实为同器型**后，缺图的一件直接以有图的同款等比例缩放锚定、只改尺寸。比泛化推断可靠，但前提是"确实同型、仅尺寸不同"已被确认。
- 【推断·依据】：缺图，按"同花纹 + 已知器型"等推出，写明依据。
- 【缺失】：该单品 / 该角度无图。
- 推断与缺失件在交付说明里显式列出；缺图导致高风险锚点无法判定时，**先问用户，不强行定稿、不出图**。

## 提取步骤

1. **系列共性**：胎釉底色与光泽（奶白暖釉/冷白亮釉/哑光陶土）、肌理、工艺观感（手绘/印花/浮雕）。
2. **逐件器型**：收/敞口、深浅、是否高脚、圈足样式、异形（椭圆/方/圆角/花边）、**比例（偏方/偏长按实物如实记，不用名字反推）**。
3. **边饰编号 A/B/C**：外缘 vs 内缘、颜色、宽度、实线/虚线/分段、波浪/光滑。
4. **花纹元素编号 F1/F2**：花种、瓣数、**花蕊**、枝叶、配色；布局必须区分 **"实心色块 / 空心线圈 / 留白"**（如中心实心绿圆徽章 ≠ 空心线圈 ≠ 盘心全空），并写明 **外壁有无花纹**。
5. **配色清单**（限定色名，画面配色不得超出）。
6. **套装单品规格表**：名称 + 尺寸 + 边饰/花纹编号 + 证据等级 + 缺图标记。

## 档案模板

```markdown
# <系列名> 特征档案
## 共性
胎釉： ；肌理： ；工艺观感：
## 逐件档案（一件一卡，含证据等级）
### <单品名>
- 器型（视角）：…【实物确认·侧视】
- 外壁花纹：…；高脚/圈足：侧视…、底视…【实物确认·侧视/底视】
- 边饰/花纹编号：…；中心：实心色块/线圈/留白
## 边饰库（A/B/C，外缘/内缘、宽/窄、线/波浪）
## 花纹元素库（F1/F2，花种/花蕊/枝叶/配色）
## 配色清单
## 布局规则（中心/沿/角，何处该空；外壁有无花）
## 单品规格表
| 名称 | 尺寸 | 边饰 | 花纹 | 证据 | 缺图角度 |
## 一致性核对清单（高风险锚点，逐条可判）
## 待用户确认（缺失/矛盾项）
```

## 建档自审（落盘前必做，挡住"错档案进入抽查"）

- 把每条高风险锚点**回到实物图再看一遍**，确认结论成立而非脑补；尤其：外壁有花否、是否高脚、碗口正圆否、中心是实心/线圈/留白、足色（按视角分开）。
- 相似相邻件并置核对是否对调。
- 汇总"缺图/与名字矛盾/看不出"的清单，**一次性问用户**；未答前相关件不强行定稿。

## 关键经验（避免重蹈）

- 边饰务必区分"外缘 vs 内缘""实线 vs 虚线""波浪 vs 光滑"，笼统写"花边"必被自由发挥。
- 明确写出"**哪里不该有花**"（散花盘心必须空），否则模型默认填满。
- 圈足/底座颜色单列，且**按视角分别记**。
- **面状图案（实心绿圆）易被画成空心线圈**，要写"实心 X 色、内部 X 纹"。
- **大汤碗 / 非高脚碗易被画成素碗**，外壁花纹必须显式写、并写明"无高脚台、浅矮圈足"。
- 缺图推断件在交付说明里显式标注，不冒充实拍。
- 档案落盘到 `products/<产品名>/特征档案.md`；同商品改图复用、不重建。
