# 实物特征档案（只记"商品本体"，轻量建档）

出图前建档。**只锁商品本身长什么样**；背景/场景/风格不用记，那部分自由发挥。档案是提示词与抽查的唯一基准，基准错了后面全错。

## 红线（违反必返工）

1. **以实物图为唯一准绳**：品名、尺寸表、常识都不能用来推断外观。名字叫"长方盘"，实物偏方就按偏方。
2. **禁止用拉伸/变形/局部重绘把器物"修"成名字或尺寸该有的样子**。
3. **不确定就先停下问用户，严禁带疑问自行出图**：缺图缺角度、实物与名字/尺寸矛盾、"是不是同款"存疑、高风险锚点拿不准，一次性列给用户，答复前不为相关件出图。
4. 每条结论都要能指到"哪件、哪张图、哪个角度"；看不到的部位标【缺失】，不拿别的件补全冒充实拍。
5. 同名不同尺寸是否同器型，只能由用户确认或实物证实。

## 用户标准拍法（角度口径，别用错）

每件通常 5 张（图0 是标签，仅看资质、不入图）：
- **图1 = 45° 角正图**（细节最多，主视觉/封面/手持）
- **图2 = 俯视**（正俯，看盘心/碗内花纹、中心实心/线圈/留白）
- **图3 = 底视（倒扣）**（看圈足形状/颜色、**底足品牌底标/底款**）
- **图4 = 侧视（水平正侧）**（看器型深浅轮廓、外壁花纹、口沿）
- **尺寸图标准三视图 = 图2 俯视 + 图4 侧视 + 图3 底视**；不要拿图1 的 45° 斜俯当侧视图。

## 轻量建档（只记高风险锚点，一件一卡）

套装逐件、按上面角度看全，每条标证据等级。重点记这些，其余从简：

- **器型/比例**：收/敞口、深浅、圆腹/斜直壁、异形、偏方偏长（如实记）。
- **外壁有无花纹**、是否高脚/高脚台颜色（只看俯拍最易漏，大汤碗/非高脚碗高发）。
- **边饰**：外缘/内缘、颜色、宽/窄、实线/虚线/波浪。
- **花纹与中心**：花种、瓣数、**花心/花蕊**、枝叶、配色；中心是实心色块/空心线圈/留白（三者不可混）；**面状实心圆要写"实心X色、内部X纹"，否则易被画成空心线圈**。
- **圈足/底标**：圈足端面颜色、足心纹；**底足上的品牌 Logo/底款/文字，实物有就照实还原，不要主动去掉**。
- **配色清单**（限定色名，画面本体配色不得超出）。
- **尺寸**：名称 + 直径/长宽/高（来自尺寸表，数字脚本叠加）。

## 证据等级

- 【实物确认·角度】：该角度实物图直接看到。
- 【同款锚定·来源款】：同名不同尺寸、经用户确认/实物证实同器型，缺图件等比例缩放、只改尺寸。
- 【推断·依据】：缺图，按已知信息推，写明依据。
- 【缺失】：无图。推断/缺失件在交付说明列出；高风险锚点无法判定时先问用户、不出图。

## 建档自审（落盘前）

- 每条高风险锚点回实物图再看一遍（外壁有花否、器型深浅、是否高脚、碗口正圆、中心实心/线圈/留白、圈足与底标、花心），相似相邻件并置防对调。
- 汇总缺图/矛盾/看不出的清单，**一次性问用户**，未答前相关件不定稿。

## 落盘与复用

- 存 `products/<产品名>/特征档案.md`；同商品改图先读、复用，不重建。
- 提示词里**本体描述写一次、多图复用**，只改场景/角度/构图。
- 档案只服务"本体一致"，不要把背景、道具、风格也写死。
