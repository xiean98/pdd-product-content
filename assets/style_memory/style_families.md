# 风格族记忆库（索引，无需用户提供参考图）

这是“记忆”：提供版式、配色、光影、道具、字体的风格倾向。**不是固定模板**——每次先由实物视觉基因选族，再用实物主色覆盖默认色，并在族内轮换构图/道具，保证不同商品不雷同。

> 每个风格族是 `families/` 下的单独文件（新增风格＝新增文件，多端并行几乎不冲突）。本文件只放匹配规则与目录。

## 匹配规则（先做这步）

按实物的【主色冷暖、花纹风格、材质光哑、器型线条】判断：
- 暖白釉 + 手绘花草、低饱和 → ①手绘田园 / ⑥奶油温柔
- 粗陶哑光 + 大地色、手作肌理 → ②日式侘寂
- 冷白 + 线条简洁、少花纹 → ③北欧极简
- 青花/水墨/缠枝、描金红黑 → ④新中式
- 深色/描金/大理石、精致 → ⑤现代轻奢
- 圆润造型 + 卡通图案/高饱和可爱色 → ⑦童趣卡通
- 蕾丝感花纹 + 莫兰迪复古色、花边口 → ⑧法式复古

拿不准时选 1 主族 + 融合 1 族；并始终以实物主色为准。

## 变化与记忆维护（跨端同步）

- 每次在 **`products/<产品名>/风格使用记录.md`** 逐行追加：`日期 | 物料 | 风格族 | 角度 | 主道具 | 主色`，同系列多图、以及下次续作之间不重复。
- 道具/角度是“可替换槽位”，按风格族库挑换；商品本身（器型/边饰/花纹）永不可变。
- 遇到库里没有的新风格：在 `families/` 新建 `序号-族名.md`，按“适配信号/配色/光影/道具/字体/构图”六要素写，并在上方目录表登记一行。
- 反复验证有效的提示词套路或新易错点，回写到 `references/` 对应模块。
- **每次改动后必须执行收工同步**（见 `scripts/sync_push.sh`），否则别的 AI/设备看不到。
