# 风格灵感库（可选，不强制使用）

> 定位已调整：**默认让模型根据商品气质自由发挥、鼓励多变**（见 `references/gallery.md`）。
> 本库只是"没灵感 / 用户点名要某种风格 / 想要统一调性"时的参考，**不强制匹配、不强制逐张记录已用组合**，更不是只能二选一的固定模板。

## 什么时候翻

- 完全没思路，想要一个起手方向；
- 用户指定了"侘寂/新中式/ins/卡通"之类调性；
- 一个系列多图想要统一基调时，挑一个族做参考，但仍要用实物主色、且在场景/构图/版式上做足差异。

## 风格族目录（families/<编号-名>.md，新增风格=新增文件）

| 族 | 文件 | 适配信号（仅供参考，不贴标签也能自由创作） |
|---|---|---|
| ① 手绘田园/治愈 | `families/01-手绘田园.md` | 手绘野花、暖白釉、手作肌理 |
| ② 日式侘寂 | `families/02-日式侘寂.md` | 粗陶哑光、大地色、不规则手作 |
| ③ 北欧极简 | `families/03-北欧极简.md` | 冷白、简洁几何、少花纹 |
| ④ 新中式 | `families/04-新中式.md` | 青花/水墨/缠枝、描金红黑 |
| ⑤ 现代轻奢 | `families/05-现代轻奢.md` | 深色、描金、大理石、金属边 |
| ⑥ 奶油风/韩系温柔 | `families/06-奶油韩系.md` | 奶白圆润、低饱和、小图案 |
| ⑦ 童趣卡通 | `families/07-童趣卡通.md` | 卡通形象、高饱和、圆润、手持/标签感 |
| ⑧ 法式复古 | `families/08-法式复古.md` | 蕾丝花边、莫兰迪复古色、做旧 |

每个 family 只列"配色/光影/道具/字体/构图"几个槽位，可整段借用、可只取一两条、也可完全不看。

## 维护（轻量）

- 反复验证有效的新风格可在 `families/` 加文件并在上面登记；**日常出图不必逐张记录"用了什么"**。
- 商品本体（器型/边饰/花纹/圈足/底标）永不可变；风格/背景/道具随意换。
- 新的、复用性强的出图套路或易错点，回写到 `references/` 对应模块。
- 文本改动按收工流程 `scripts/sync_push.sh` 同步即可。
