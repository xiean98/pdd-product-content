# pdd-product-content

拼多多 / 淘宝等电商的商品内容一站式生成 **Skill**。输入「商品品名 + 实物图」，产出一套可直接上架的图文物料，并在多台设备、多个 AI 之间通过 Git 共享同一份「风格记忆」和「产品档案」。

> 给 AI 的话：加载后以 `SKILL.md` 为准执行；本页是仓库导航与说明。

## 能产出什么

- 商品标题（符合平台关键词公式与合规红线）
- 轮播图（默认 10 张 1536 方图、无文字、多角度多场景）
- 封面主图（3–5 张）
- 尺寸标注图（俯视/侧视/底视 + 细灰标注线）
- 详情页（默认竖版 10 屏 + 工艺说明、温馨提示尾部两屏）

## 三个核心特点

1. **风格自适应，不千篇一律**：内置风格族库，先由实物视觉基因匹配风格族，再用实物主色定调，构图/道具/角度在族内轮换，无需用户每次提供参考图。
2. **商品必须与实物一致**：先建结构化「特征档案」（器型/边饰/花纹/配色/圈足），提示词逐件锁定，再做风险分级抽查（首件全检 → 其余抽高风险锚点 → 命中错误整批升级全检）。
3. **跨端记忆自动同步**：本目录即 Git 仓库，开工 `pull`、收工 `push`；新风格族、产品档案、经验在多设备/多 AI 间持续积累。

## 标准输入

- 商品品名（没有成品名可给关键词方向）。
- 每件实物图 **4 张**：①45° 角正图（细节多）②侧视 ③俯视 ④底视；套装每件各 4 张。
- 可选：尺寸表（直径/长宽/高）、件数清单、已确认的材质/工艺。

## 快速开始

- **使用 skill**：在装有本 skill 的环境里直接说「给这个商品做一套拼多多图」，并给品名 + 4 张实物图/件。
- **新设备 / 新 AI 接入**：见 [SETUP.md](./SETUP.md)。
- **日常同步**：
  ```bash
  bash scripts/sync_pull.sh                        # 开工
  bash scripts/sync_push.sh "feat(<产品>): 改动"   # 收工
  ```

## 工作流概览

```
开工 pull → 盘点输入 → 建/复用特征档案 → 拟标题 → 出图（轮播/封面/尺寸/详情）
        → 抽查自检 → 交付 → 记录风格组合 → 收工 push
```

## 默认合规口径（陶瓷餐具）

- 不写容量；可写「可微波炉加热」；洗碗机/烤箱未确认不写；礼盒、售后暂不上屏。
- 釉上/下彩、骨瓷、耐温、产地、品牌、发货时效、"食品级"等未确认信息一律不写。
- 换品类（玻璃/塑料/金属/竹木）时，功能适用性需重新确认。

## 说明

- 本仓库为**私有**；只对文本记忆做版本管理，原图/成品图/压缩包不进 Git（见 `.gitignore`），统一放飞书云盘或项目空间。
