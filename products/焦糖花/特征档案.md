# 焦糖花系列 · 设计特征档案（提示词与自检基准）

## 一、系列共性（所有单品通用）
- **釉色**：奶白偏暖（象牙白/米白），不是冷白、纯白。
- **质感**：釉面带轻微手工凹凸/刷纹肌理（手作感、微微磨砂），光泽柔和，不是光滑高亮白瓷。
- **工艺**：釉下彩，手绘水彩晕染风格，花色边缘有自然晕开感。
- **配色**：焦糖棕、鹅黄、矢车菊蓝（灰蓝/雾霾蓝）、浅粉、橄榄绿枝叶。
- **花种（元素库）**：
  - F1 蓝色大花：8–10 瓣圆润花瓣，**黑色密集小圆点花蕊**（似银莲花）。
  - F2 焦糖棕大花：多瓣，**白色小圆点花蕊**。
  - F3 鹅黄五瓣花：中心深色小点+白圈。
  - F4 蓝色五瓣小花：白色/深色蕊。
  - F5 粉色郁金香/百合：杯状，顶端黄色小点花蕊。
  - F6 粉色小碎花簇：3–5 朵极简五瓣小花连成细枝（雪柳/满天星感）。
  - F7 橄榄绿枝叶：椭圆小叶，手绘线条带叶脉。
  - F8 单独双叶/枝叶小图案。

## 二、边饰体系（最易出错，务必区分）
- **A 类｜棕色宽边 + 白色双竖线分段**：口沿/盘沿一圈较宽焦糖棕带，被成对白色短竖块“||”均匀打断（约 6–8 组）；最外缘另有细棕描边。
- **B 类｜棕+豆绿方格边 + 内缘虚线环 + 花散宽沿 + 中心空**：最外缘是棕色与浅薄荷绿小方格交替的格纹窄边；宽沿上散花；内缘一圈棕色虚线（方格点）环；中心留白。
- **C 类｜黑色波点窄边**：口沿下浅褐/米色窄边，上有均匀黑色圆点。
- **D 类｜棕描边 + 棕色虚线内框 + 花散四角 + 中心空**（方形器）。

## 四、一致性核对清单（自检逐项打勾）
1. **器型**：轮廓曲线/深浅/圈足是否与实物一致？
2. **边饰类别**：A/B/C/D 是否正确（宽边分段 / 方格+虚线环 / 波点 / 虚线框）？
3. **花纹种类**：该有的 F1–F8 是否齐全、有无多造花？
4. **花色**：每朵花颜色（蓝/棕/黄/粉）是否对、花蕊颜色（黑点/白点）是否对？
5. **位置与组织**：中心花束 vs 宽沿散花 vs 四角散绘是否正确？中心该空的是否空？
6. **釉色质感**：是否奶白暖调+手作肌理，而非冷白光滑？
7. **标题文字**：文案与字数是否准确无误？

> 关键负面约束：不要冷白/纯白光滑瓷；不要绿色宽边；不要混用边饰（如给 A 类碗加格纹）；不要改变或新增花卉；不要把散花画成中心花束（或反之）。
